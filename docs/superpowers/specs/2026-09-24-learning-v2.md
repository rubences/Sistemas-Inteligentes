7. Global search across 335 slide titles, text and notes; a 30+ term English/Spanish glossary; an accessible concept map and paired study view.
8. Optional class service: teacher-authenticated rooms, polls, pseudonymous student join, submissions, teacher feedback, aggregate progress and CSV export. A real service implemented and tested locally, not a fake live dashboard. GitHub Pages hosts only the client. No hosting credentials or server destination were supplied; external deployment is an explicit operational dependency.
9. LMS integration package: Moodle XML question bank, assignment briefs/rubrics, submission report, and installation guide. No claim of live university integration or trusted client-side grades.

Extend version-1 progress with an optional validated learning field and accept old backups unchanged. No accounts or server are required for static study.
