Zero-sum means U_MIN=−U_MAX, or an equivalent constant-sum normalization. Completeness needs termination. A finite branching factor alone does not make an unbounded game tree finite. Teaching and study notes

This is the central pruning argument. A skipped branch is not illegal or impossible. Its exact result is unnecessary for the current root decision. Alpha–beta bounds

The search carries a window of relevant values

α: lower thresholdAn alternative already available to MAX along the current search path.
β: upper thresholdAn alternative already available to MIN along the current search path.
CutoffStop remaining children when α ≥ β.

Bounds are relative to the current search context. They are not exact values of every descendant.

Adapted from the supplied Unit 5 material27 / 60
Teaching and study notes

The root starts with alpha=-infinity and beta=+infinity. At a MAX node, a better child can raise alpha. At a MIN node, a lower child can lower beta. Calling these guaranteed alternatives is meaningful relative to the ancestors that control the corresponding decisions. A subtree searched under a narrow window may return only a bound.

Alpha–beta

One recursive function with bounds

AB(s, depth, α, β):
    if Terminal(s): return Utility(s)
    if depth == 0: return Eval(s)
    v ← -infinity if Player(s)==MAX else +infinity
    for a in ordered_actions(s):
        child ← AB(Result(s,a), depth-1, α, β)
        if Player(s)==MAX:
            v ← max(v, child); α ← max(α, v)
        else:
            v ← min(v, child); β ← min(β, v)
        if α ≥ β: break
    return v

At the root, record an action only on strict improvement of its current best score.

Expanded source alpha-beta pseudocode29 / 60
Teaching and study notes

This is a fail-soft form: it returns the computed v even if it lies outside the original search window. At the root, initialize an available legal action and keep the first action on equal scores. A cutoff value from another root child can be a bound, so replacing an exact best action merely on equality can be wrong. Terminal checks precede heuristic cutoffs.

Learning check

Six distinctions that prevent search errors

01

Why does MIN take a minimum?

Values use MAX’s perspective, and the zero-sum opponent prefers the least favourable outcome for MAX.
02

What does a cutoff score prove?

It is a result for the truncated tree and chosen evaluator, not generally the exact full-game value.
03

When can alpha-beta stop?

When α≥β makes the remaining children irrelevant to the established root decision.
04

Can a pruned node return a bound?

Yes. A MAX cutoff gives a lower bound; a MIN cutoff gives an upper bound.
05

Does ordering change the optimal value?

For the same tree and leaf values, no. It changes work and can change the selected tied optimal action.
06

Why average at chance nodes?

The model assigns probabilities to outcomes. Expected utility combines their values with those weights.
