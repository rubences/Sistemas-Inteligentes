Foundations

Known cost and estimated cost

g(n)

The accumulated cost of the path represented by node n.

h(s)

An estimate of the cheapest remaining cost from state s to a goal.

Two nodes can share a state and h value while having different paths and g values.

Adapted from the supplied Unit 3 material03 / 60
Teaching and study notes

Use h(n) as shorthand for h(n.state). A state is a configuration. A node also carries a parent, action and accumulated path cost. The cost g is exact for that particular path, but it is not necessarily the cheapest known cost to the state. Search priorities apply to candidate nodes. This distinction is essential for improvements and reopening.

An f value is not necessarily the cost of any actual complete route. It combines an actual prefix with an optimistic suffix. The same state reached via a cheaper prefix receives a smaller f. This is why changing only a state label without replacing its parent and g would be an incorrect update.

A*

Graph A* with best-cost improvements

best[start] ← 0
push(root(start), priority=h(start))
while frontier is not empty:
    n ← pop_min_f()
    if n.g != best[n.state]: continue
    if goal(n.state): return reconstruct(n)
    for (a, s, cost) in successors(n.state):
        new_g ← n.g + cost
        if new_g < best.get(s, infinity):
            best[s] ← new_g
            push(Node(s, n, a, new_g), new_g + h(s))
return FAILURE

A cheaper path can be queued even when the state was expanded earlier.

Original pseudocode consistent with the stated A* policy13 / 60
Teaching and study notes

This explanatory version uses lazy duplicate entries and allows reopening. A node stores state, parent, action and g; a real implementation may also store depth, h and a sequence number. Because improvements are strict, equal-cost rediscoveries do not create more entries. The stale check precedes the goal test. A state-based deterministic heuristic makes a best-g improvement also an f improvement.

Queue entries and state records have different jobs

best[state]The smallest g discovered so far for that state.
Queue entryAn immutable candidate path with its own g, parent and priority.

Original implementation clarification14 / 60
Teaching and study notes

A priority queue does not usually repair its ordering if a field inside an enqueued object changes. Creating a fresh immutable entry and skipping stale ones is a simple approach. Keep the best-state record separate from the historical node needed for parent reconstruction. Stale entry rejection and reopening are related but distinct mechanisms.

Adapted from the supplied Unit 3 material15 / 60
Teaching and study notes

Our convention includes nonnegativity. Some definitions allow negative admissible values, but that is not needed in this course. If a state has no route to a goal, h* can be treated as infinity. A proof must cover the states on which the heuristic will be used. One state with h greater than a verified solution cost is enough to refute a lower-bound claim.

Consistency constrains every legal step

h(s) ≤ c(s, a, s′) + h(s′)

Local interpretation

The estimate cannot drop by more than the cost of taking one step.

Goal boundary

Set h(goal) = 0.

The inequality applies to every directed transition.

Consistency plus the goal boundary implies admissibility for states that can reach a goal.

Adapted from the supplied Unit 3 material16 / 60
Teaching and study notes

Apply the inequality along any legal path from s to a goal. The heuristic terms telescope, leaving h(s) no greater than that path’s total cost. Taking the cheapest path gives admissibility. The h(goal)=0 boundary is essential: edge inequalities alone also hold for an arbitrary constant positive function, which overestimates at the goal.

The nondecreasing property refers to f along a path. A consistent graph A* can safely close a state when it is removed, assuming valid cost handling and a fixed goal. The Weighted A* cost bound

C_returned ≤ w C*

For fixed w ≥ 1 with an admissible nonnegative h and h(goal)=0.

Implementation conditions

Nonnegative action costs, minimum-priority removal, valid best-g improvements and reopening when required.

Termination

A finite reachable graph suffices here. Infinite spaces need further completeness assumptions.

An arbitrary overestimating heuristic does not inherit this weight bound.

Hansen & Zhou (2007), Anytime Heuristic Search · Bound explanation47 / 60
Teaching and study notes

A frontier node on an optimal path has g+w h≤w(g+h*)=w C*, since g≥0. Correct improvements preserve such a prefix until the goal is selected. The selected goal has h=0, so its cost cannot exceed that candidate priority. Do not transfer the ordinary consistent-A* no-reopening rule to Weighted A* without another argument. This is a cost bound, not a prediction of the actual error.

Synthesis

Six checks for optimal A*

01

What does g describe?

The exact cost of this candidate path, not necessarily the cheapest path to its state.
02

What does admissibility require?

A lower bound on remaining cost for every relevant state.
03

What does consistency add?

An inequality for every legal edge, with h(goal)=0.
04

When might A* reopen a state?

When an inconsistent heuristic lets it expand a state before a cheaper path arrives.
05

Why can a raw Loopover count fail?

One coupled unit-cost action moves seven distinct tiles.
06

When can PDB values be added?

When a valid cost allocation prevents counting the same action cost more than once.
