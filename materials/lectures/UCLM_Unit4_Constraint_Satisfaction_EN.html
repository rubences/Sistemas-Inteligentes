In ordinary finite satisfaction problems, we do not minimize the number of assignments made while solving. Those assignments are an algorithmic process, not an application plan. A planning problem can also be encoded as a CSP, for example with variables indexed by time, but its modelling assumptions must be explicit. This unit focuses on finite-domain CSPs.

Domains DFor each Xᵢ, a finite set Dᵢ of candidate values.

A solution assigns one value to every variable and satisfies every constraint.

Adapted from the supplied Unit 4 material04 / 54
Teaching and study notes

A constraint has a scope, the variables it mentions, and a relation over their domains. Domains need not all have the same size or value type. A candidate in a domain is not necessarily part of any complete solution. Distinguish the original domains from the current domains after pruning. With n variables and at most d values each, there are at most d^n complete assignments.

Systematic search

Backtracking builds one assignment at a time

01SelectChoose an unassigned variable.
02TryAssign a value that passes local checks.
03InferPrune values and detect failure.
04Recurse / undoContinue or restore and try the next value.

Assign one variable per level: avoid permuting the order of the same decisions.

Adapted from the supplied Unit 4 material13 / 54
Teaching and study notes

Assignments are commutative in the sense that their final set of variable-value pairs does not depend on construction order. A backtracking solver chooses a single variable at each node and branches over its values. This avoids a redundant factor from trying all variable assignment orders. It does not remove the exponential worst case.

UCLMUniversidad de Castilla-La Mancha
Systematic search

A solver needs an explicit undo operation

solve(assignment, domains):
    if complete(assignment): return copy(assignment)
    X ← choose_unassigned_variable(assignment, domains)
    for value in ordered_values(X, domains):
        if consistent(X=value, assignment):
            mark ← trail.checkpoint()
            assign(X, value); restrict_domain(X, {value})
            if propagate(domains) != FAILURE:
                result ← solve(assignment, domains)
                if result != FAILURE: return result
            unassign(X); trail.restore(mark)
    return FAILURE

Every domain change in the failed branch must be undone before the next value.

Expanded source pseudocode · Reversible domain updates14 / 54
Teaching and study notes

The initial domains should first pass the relevant unary filtering. The base case assumes each assignment and inference step preserves all applicable constraints; a final independent solution validator is still useful. A trail records reversible changes, while copying domains at each node is a simpler teaching alternative. Completeness requires all remaining values to be tried, sound pruning and no premature resource cap.

Arc consistency

Every value needs a supporting value

Xᵢ → Xⱼ

For each a in D(Xᵢ), there must be some b in D(Xⱼ) satisfying the binary relation.

REVISE removes from the tail

If a has no support, delete a from D(Xᵢ).

The reverse arc must be checked separately.

Support is existential and local: different values may rely on different supports.

Adapted from the supplied Unit 4 material24 / 54
Teaching and study notes

For the constraint X<Y, the reverse check uses the same relation with the arguments correctly oriented: a Y value needs a smaller X value. It does not impose Y<X. Arc consistency assumes constraints can be evaluated for pairs of domain values. Multiple constraints on the same pair can be combined as one conjunctive binary relation.

Arc consistency

AC-3 propagates changes through a queue

Q ← all directed arcs
while Q is not empty:
    (Xi, Xj) ← Q.pop_front()
    if REVISE(Xi, Xj):
        if D(Xi) is empty: return FAILURE
        for Xk in neighbours(Xi), Xk != Xj:
            add (Xk, Xi) to Q if not already queued
return ARC_CONSISTENT

A smaller D(Xᵢ) can remove supports for values in its other neighbours.

Supplied AC-3 algorithm · Explicit return semantics26 / 54
Teaching and study notes

REVISE returns true only if it deletes at least one value from the first variable. The excluded reverse arc cannot have lost support through this revision when the two directed checks use the same binary relation with correct argument orientation. Reject an initially empty domain before running the queue. The return status deliberately says ARC_CONSISTENT, not SOLVED.

Teaching and study notes

Local search

Start complete, then repair conflicts

Backtracking

Keep a partial assignment and extend it while detecting contradictions.

Local repair

Keep every variable assigned, even if constraints are violated, and change selected values.

Completeness of an assignment is not completeness of an algorithm.

Adapted from the supplied Unit 4 material38 / 54
Teaching and study notes

A complete N-Queens state has one queen in every column but can contain many attacking pairs. A complete algorithm is one that is guaranteed to find a solution when one exists under its assumptions. These uses of the word complete must not be confused. Local repair can work very well on suitable large instances, but a finite unsuccessful run does not establish unsatisfiability.

    state[X] ← value          # random tie breaking
if all constraints hold: return SOLUTION(state)
return BUDGET_EXHAUSTED

A best repair can leave the score unchanged. Plateaus and repeated states are possible.

Six questions to carry forward

01

What defines a CSP?

Variables, one domain per variable and constraints over their values.
02

Does partial consistency imply a solution?

No. A partial assignment can violate no assigned relation and still have no completion.
03

What does MRV select?

An unassigned variable with the fewest currently legal values.
04

What must backtracking restore?

The assignment and every branch-specific domain removal.
05

Does AC-3 prove satisfiability?

Not generally. A two-colour triangle is arc-consistent but unsatisfiable.
06

What does a min-conflicts limit prove?

Only that this run used its budget without a solution; it does not prove UNSAT.
